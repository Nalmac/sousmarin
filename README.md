# Détail du projet
L'objectif de ce projet a été de développer un firmware pour contrôler les ballasts d'un sous-marin miniature, à l'occasion du TIPE (Travail d'Initiative Personnelle Encadré) durant ma classe préparatoire. 
Ce TIPE a été plutôt bien reçu lors des concours qui l'ont sanctionné (17 aux ENS).
